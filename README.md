# OTHS Geography & Earth Science Club

Website for the Geography & Earth Science Club at Obra D. Tompkins High School.

Meetings are Tuesdays in Room 1636 (Ms. Glasgow's room).

## Structure

- `index.html` — the whole site, one page
- `styles.css` — all styling
- `assets/` — club crest and the topographic background

Static HTML. No build step, no dependencies. Open `index.html` to view it locally.
